## 概述

**系统配置中心**提供了可视化的界面来管理应用的核心元数据。配置页面主要包含三个核心模块：

1.  **🗺️ 路由管理** (Route Management) - 定义系统的顶级功能模块（如：`/dashboard`）。
2.  **📋 菜单管理** (Menu Management) - 定义左侧导航栏的树形结构。
3.  **📄 页面管理** (Page Management) - 管理页面内容模板及 AI 工作流集成。

## 路由管理

### 功能说明
路由管理用于定义系统的顶级入口（一级路由）。每个路由对应一个独立的功能模块（Namespace）。

### 字段说明

| 字段名 | 说明 | 必填 | 格式/备注 |
| :--- | :--- | :--- | :--- |
| **路由标识** (`route_key`) | URL 路径的一部分 | ✅ | 只能包含字母、数字、下划线。例如 `analytics`，系统将生成 `/analytics` 路径。 |
| **路由名称** (`route_name`) | 显示名称 | ✅ | 例如：`数据分析` |
| **组件类型** (`component_type`) | 渲染方式 | ✅ | • **动态页面** (推荐)：使用系统内置页面构建器<br>• **静态组件**：开发人员手写的代码组件 |
| **组件路径** (`component_path`) | 代码路径 | ❌ | 仅当类型为“静态组件”时填写 |
| **排序** (`order_num`) | 显示顺序 | ❌ | 数字越小越靠前 |

### 操作指南
*   **新建路由**：点击“新建路由”按钮，填写标识和名称。注意 `route_key` 一旦创建不可修改。
*   **删除路由**：仅能删除非核心路由。系统预置的 `dashboard` 和 `system` 路由无法删除。

## 菜单管理

### 功能说明
菜单管理用于创建、编辑和删除系统的左侧导航菜单。菜单项通过 `Page Key` 与具体的页面内容关联。

### 字段说明

| 字段名 | 说明 | 必填 | 备注 |
| :--- | :--- | :--- | :--- |
| **菜单名称** (`label`) | 导航栏显示的标题 | ✅ | |
| **副标题** (`subtitle`) | 下方辅助说明文字 | ❌ | **[新功能]** 用于增强语义提示 |
| **Page Key** | 页面唯一标识 | ✅ | 用于关联页面模板，系统会自动确保唯一性 |
| **图标** (`icon`) | 菜单图标 | ❌ | 支持 FontAwesome 类名，如 `fa fa-home` |
| **所属路由** (`route_key`) | 归属模块 | ✅ | 选择该菜单属于哪个顶级路由 |
| **上级菜单** (`parent_id`) | 父级菜单 | ❌ | 选择后将作为子菜单显示 |

### 操作指南
1.  **新建菜单**：
    *   输入 `Page Key` (如 `loan_risk`)，系统会自动生成访问路径。
    *   支持设置 **副标题**，在菜单名称下方以小字显示，提升用户体验。
2.  **筛选**：可通过“所属路由”下拉框快速筛选特定模块下的菜单。

## 页面管理

### 功能说明
页面管理是系统的核心，用于维护每个页面的 UI 结构（基于 AMIS Schema）以及配置 AI 能力。

### 页面列表与版本
*   **版本控制**：列表显示当前激活的页面版本 (`version`) 和更新时间。
*   **筛选**：可按“所属路由”或“所属菜单”查找页面。

### 编辑页面配置
点击操作栏的 **“编辑配置”** 按钮，将打开可视化/代码编辑器：
*   **Schema 编辑**：直接修改页面的 AMIS JSON 配置。
*   **实时生效**：提交后，前端会有缓存刷新机制。

### AI 工作流配置 (AI Integration)

点击操作栏的 **“AI工作流”** 按钮，可为该页面绑定 Dify 工作流。

#### 1. 添加工作流
在弹出的对话框中点击“添加工作流”，填写以下参数：

| 参数 | 说明 | 示例 |
| :--- | :--- | :--- |
| **工作流名称** | 自定义名称 | `风险报告生成器` |
| **类型** | 业务场景分类 | • **AI 分析** (`ai_analysis`)<br>• **报告生成** (`report_generation`)<br>• **数据导入** (`data_import`) |
| **API 地址** | Dify API URL | `https://api.dify.ai/v1` |
| **API Key** | 应用密钥 | `app-xxxxxxxx...` |
| **状态** | 启用开关 | 只有启用的工作流才会显示在页面上 |

#### 2. 工作流类型说明
*   **AI 分析**: 对页面表格数据进行智能解读。
*   **报告生成**: 根据数据一键生成 Word/PDF 报告。
*   **数据导入**: 智能解析非结构化文件（Excel/PDF）并导入系统。

## 后端配置

### 功能说明
为了确保系统的稳定性和安全性，核心后端参数（如端口、鉴权密钥、网关开关等）均通过**环境变量**进行管理。这些变量通常定义在服务器部署目录下的 `.env` 文件中，或直接在 `docker-compose.yml` 的 `environment` 节点中配置。这意味着它们在配置中心界面上是**不可见或只读**的，无法通过前端直接修改。

### 核心配置项列表
您可以在部署配置文件（`.env` 或 `docker-compose.yml`）中找到以下配置：

| 环境变量名 | 说明 | 示例值 |
| :--- | :--- | :--- |
| `PORT` | 后端服务监听端口 | `3001` |
| `API_ROUTE_PREFIX` | 接口统一前缀 | `/gjjrgzn/api` |
| `JWT_SECRET` | 登录鉴权加密密钥 | *(建议设置为复杂随机字符串)* |
| `GATEWAY_ENABLED` | 第三方网关集成开关 | `true` 或 `false` |
| `DB_PATH` | SQLite 数据库文件路径 | `./data/database.sqlite` |

> **⚠️ 注意**: 修改环境变量后，必须**重启后端服务**（或重建容器）才能生效。

## 常见问题

### Q1: 删除了通过“路由管理”创建的路由，该路由下的菜单还在吗？
**A**: 菜单数据仍然存在，但因为失去了父级路由，它们可能无法在导航栏正常显示。建议在删除路由前，先清理或迁移其下的菜单。

### Q2: 为什么我看不到“后端配置”了？
**A**: 最新的配置中心将侧重点聚焦在 UI 和 业务元数据管理。系统级的后端参数（如限流、日志级别）现已移至服务器端的配置文件 (`.env`) 或专用的运维管理面板中进行维护。
