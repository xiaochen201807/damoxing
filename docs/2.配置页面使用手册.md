## 1. 准备工作

在开始配置之前，请确保您已经完成了系统的基础环境部署：

*   **部署状态**: 请参考《1.运维部署手册.md》完成 Docker 容器的启动，并确保服务状态为 `Up (healthy)`。
*   **访问验证**: 确保能够通过浏览器访问系统的健康检查接口（如 `http://<服务器IP>:3001/health`），返回状态正常。

---

## 2. 第一步：集成到贝贝系统

本项目（公积金 AI 大模型应用）通常作为子系统集成在“贝贝”统一管理平台中。请按照以下步骤添加菜单入口，使用户能够访问本系统。

1.  登录“贝贝”管理平台。
2.  进入 **“系统设置” -> “菜单管理”**。
3.  点击 **“新增菜单”**，填写以下信息：
    *   **菜单名称**: 公积金 AI 大模型（或自定义名称）
    *   **链接地址**: `http://<部署服务器IP>:3001` (请替换为实际 IP)
    *   **打开方式**: 新窗口打开 / 内嵌 Iframe (推荐内嵌以保持体验一致)
4.  保存并分配权限给相关角色。

![贝贝系统集成示例](./assets/beibei_integration.png)

完成后，用户即可通过贝贝平台的左侧导航栏点击进入本系统。

## 3. 功能配置指南

进入系统后，点击右上角的 **“系统配置”** 图标进入配置中心。配置中心是系统的“大脑”，用于定义系统的结构、页面和逻辑。

### 3.1 路由管理 (Route)
**用途**：当您需要开启一个新的**独立业务板块**时使用。

*   **场景示例**：比如系统原本只有“数据分析”，现在要新增“信用管理”模块。
*   **如何使用**：
    1.  点击“新建路由”。
    2.  填写 **路由标识** (如 `credit_mgr`)，这将作为 URL 的一部分。
    3.  填写 **路由名称** (如 `信用管理`)。
*   **注意**：路由是顶层容器，通常不需要频繁变动。

![路由管理界面](./assets/route_usage.png)

### 3.2 菜单管理 (Menu)
**用途**：定义用户在左侧看到的**导航树**。

*   **场景示例**：在“信用管理”板块下，添加“企业信用评分”菜单。
*   **如何使用**：
    1.  选择 **所属路由**（如 `信用管理`）。
    2.  点击“新建菜单”。
    3.  填写 **菜单名称** 和 **Page Key**（页面唯一标识，如 `ent_score`）。
    4.  如果需要二级菜单，请在 **上级菜单** 中选择父节点。

![菜单管理界面](./assets/menu_usage.png)

### 3.3 页面管理 (Page)
**用途**：创建和维护具体的**功能页面**。

*   **场景示例**：配置“企业信用评分”页面的具体内容，如查询表格、图表等。
*   **如何使用**：
    1.  在列表中找到对应的 Page Key。
    2.  点击 **“编辑配置”**：打开可视化编辑器，拖拽组件设计页面 UI。
    3.  点击 **“AI工作流”**：为页面绑定智能能力（见下文）。
*   **AI 能力配置**：
    *   **AI 分析**：让 AI 自动解读页面表格中的数据。
    *   **报告生成**：配置 AI 读取数据并生成 Word/PDF 报告供下载。
    *   **数据导入**：配置 AI 助手来解析上传的非结构化文件。

![页面管理与AI配置](./assets/page_ai_config.png)

### 3.4 页面模板 (Template)
**用途**：利用现成的样板**快速复制**页面。

*   **场景示例**：您还是想要一个“信用评分”页，但不想从头设计，想复用系统中已有的“风险评估”页面的布局。
*   **如何使用**：
    1.  在新建页面时，选择“从模板创建”。
    2.  浏览模板库，选择合适的业务场景模板（如：标准 CRUD 列表、综合分析大屏）。
    3.  系统将自动复制该模板的布局和逻辑，您只需微调数据源即可。

![页面模板选择](./assets/template_selection.png)

### 3.5 后端管理 (Backend)
**用途**：管理系统的**全局参数**和**连接配置**。

*   **场景示例**：修改 AI 服务的连接地址，或者更换第三方网关的校验接口。
*   **如何使用**：
    *   **参数配置**：在配置页面的“后端配置”标签页中查看当前生效的参数。
    *   **修改参数**：为了安全起见，核心参数（如密钥、数据库路径）通常在服务器端的 `docker-compose.yml` 文件中修改，修改后需重启服务生效。
    *   **服务状态**：查看系统运行日志和健康状态。

![后端参数查看](./assets/backend_check.png)

## 4. 常见问题

**Q: 我在“菜单管理”里加了菜单，为什么左侧导航栏没显示？**
A: 请检查该菜单的“状态”开关是否已开启。另外，请确认您当前所在的“路由”模块与该菜单的“所属路由”一致（不同路由下的菜单是隔离显示的）。

**Q: 页面修改后，前台没变化？**
A: 这是为了性能考虑，前台会有短暂缓存。请尝试强制刷新浏览器 (Ctrl+F5 或 Shift+Cmd+R)。

**Q: 如何配置 AI 功能？**
A: 进入“页面管理”，找到对应页面，点击操作栏的“AI工作流”按钮。您需要填入 Dify 平台的 API Key 和 URL。如果您没有 Dify 账号，请联系技术支持。

## 后端配置

### 功能说明
为了确保系统的稳定性和安全性，核心后端参数（如端口、鉴权密钥、网关开关等）均通过**环境变量**进行管理。这些变量通常定义在服务器部署目录下的 `.env` 文件中，或直接在 `docker-compose.yml` 的 `environment` 节点中配置。这意味着它们在配置中心界面上是**不可见或只读**的，无法通过前端直接修改。

### 核心配置项列表
您可以在部署配置文件（`.env` 或 `docker-compose.yml`）中找到以下配置：

| 环境变量名 | 说明 | 示例值 |
| :--- | :--- | :--- |
| `PORT` | 后端服务监听端口 | `3001` |
| `API_ROUTE_PREFIX` | 接口统一前缀 | `/gjjrgzn/api` |
| `JWT_SECRET` | 登录鉴权加密密钥 | *(建议设置为复杂随机字符串)* |
| `GATEWAY_ENABLED` | 第三方网关集成开关 | `true` 或 `false` |
| `DB_PATH` | SQLite 数据库文件路径 | `./data/database.sqlite` |

> **⚠️ 注意**: 修改环境变量后，必须**重启后端服务**（或重建容器）才能生效。

## 常见问题

### Q1: 删除了通过“路由管理”创建的路由，该路由下的菜单还在吗？
**A**: 菜单数据仍然存在，但因为失去了父级路由，它们可能无法在导航栏正常显示。建议在删除路由前，先清理或迁移其下的菜单。

### Q2: 为什么我看不到“后端配置”了？
**A**: 最新的配置中心将侧重点聚焦在 UI 和 业务元数据管理。系统级的后端参数（如限流、日志级别）现已移至服务器端的配置文件 (`.env`) 或专用的运维管理面板中进行维护。
