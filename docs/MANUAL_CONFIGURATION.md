# ⚙️ 功能配置与使用手册

本文档主要面向系统管理员，详细介绍如何通过“配置中心”对系统进行功能管理，涵盖菜单配置、页面模板、AI 工作流集成及第三方网关对接。

---

## 1. 配置中心概览

配置中心是系统的核心管理模块，通常位于导航栏的**系统管理 (System)** 目录下。它提供了可视化的界面来动态调整系统的行为，无需修改代码。

### 核心模块
*   **菜单管理**: 定义左侧导航栏的结构、图标及跳转逻辑。
*   **页面管理**: 管理 AMIS 页面模板及其版本控制。
*   **AI 工作流**: 配置与 Dify 大模型平台的集成对接。
*   **后端配置**: 调整系统级参数（如 API 限流策略）。

---

## 2. 菜单与路由管理 (Menu Management)

### 2.1 新增/编辑菜单

在菜单管理列表中，您可以创建新的菜单项。系统采用了智能关联逻辑，简化了配置流程。

**关键字段说明**：

| 字段名 | 必填 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| **菜单名称** | ✅ | 导航栏显示的标题 | `贷后风险分析` |
| **副标题** (Subtitle) | ❌ | **[新功能]** 菜单下方的辅助说明文字，用于增强语义 | `实时监控` |
| **Page Key** | ✅ | 页面的唯一英文标识。系统会自动根据此标识生成访问路径 `/dashboard/{page_key}` | `risk_analysis` |
| **图标** | ❌ | 支持 FontAwesome 图标类名 | `fa fa-chart-line` |
| **所属路由** | ✅ | 选择该菜单归属的顶级模块 | `dashboard` |
| **上级菜单** | ❌ | 若为二级菜单，请选择父级 | `无` |

### 2.2 Page Key 自动关联机制

为了避免手动输入的繁琐和错误，系统实现了 `Page Key` 自动关联：
1.  **输入校验**: `Page Key` 只能包含字母、数字及下划线，且在全系统中唯一。
2.  **自动填充**: 当您在后续的“页面管理”或“AI 配置”中选择该菜单时，系统会自动填充对应的 `Page Key`，无需重复记忆。

## 3. 页面与 AI 工作流集成

### 3.1 页面模板管理 (Page Templates)

在此模块中，您可以定义页面的 UI 结构（基于 AMIS Schema）。

*   **版本控制**:
    *   **激活版本** (`is_active=1`): 当前用户实际看到的版本。
    *   **历史版本**: 编辑时建议先“另存为”新版本，测试无误后再激活，实现安全回滚。
*   **关联菜单**: 创建模板时，直接在下拉框选择对应的“菜单”，系统会自动绑定 ID。

### 3.2 AI 工作流配置 (Dify Integration)

系统支持为每个页面绑定独立的 Dify AI 工作流，实现“智能分析”、“报告生成”等功能。

**配置参数**:

*   **工作流名称**: 自定义名称（如：`风险报告生成助手`）。
*   **API URL**: Dify 平台的 API 服务地址（通常以 `/v1` 结尾）。
*   **API Key**: 在 Dify 应用设置中生成的 `App Key` (通常以 `app-` 开头)。
*   **启用状态**: 开关控制，关闭后页面上的 AI 按钮将隐藏。

## 4. 第三方网关集成 (Gateway)

本系统支持通过 URL 参数模式与第三方统一门户进行单点登录 (SSO) 集成。

### 4.1 集成原理

外部系统通过 IFrame 或重定向方式访问本系统时，需在 URL 中携带认证票据。前端自动捕获这些参数并提交给后端进行验证。

### 4.2 URL 参数规范

**格式示例**:
```
https://your-app-domain/gjjrgzn/login?ticket=XXX&tyLoginToken=YYY&qycode=ZZZ
```

**参数详解**:

| 参数名 | 必填 | 描述 | 用途 |
| :--- | :--- | :--- | :--- |
| `ticket` | ✅ | 票据凭证 | 用于后端向网关验证身份 |
| `tyLoginToken` | ✅ | 登录令牌 | 配合 ticket 完成验证 |
| `qycode` | ❌ | 租户/企业代码 | 系统会自动存储并传递给后续业务接口 |

### 4.3 调试技巧

如果您在开发环境中无法连接真实网关，可通过 `.env` 文件配置模拟参数：

```ini
# 启用网关集成
GATEWAY_ENABLED=true

# 设置默认票据 (仅当 URL 无参数时生效)
GATEWAY_TICKET=dev_ticket_123
GATEWAY_LOGIN_TOKEN=dev_token_456
```

## 5. 系统高级配置

在“后端配置”模块中，您可以调整系统的运行策略。

### API 限流策略 (Rate Limiting)

为了防止恶意请求或 AI 接口滥用，系统内置了两级限流器。

*   **Global Rate Limit** (全局限流):
    *   `global_rate_limit_window`: 窗口时间 (毫秒)，默认 15 分钟。
    *   `global_rate_limit_max`: 最大请求数，默认 100 次/IP。

*   **AI Rate Limit** (AI 专用限流):
    *   `ai_rate_limit_window`: 窗口时间 (毫秒)，默认 1 分钟。
    *   `ai_rate_limit_max`: 最大请求数，默认 10 次/IP。

> ⚠️ **注意**: 修改上述配置后，需要重启后端服务 (`docker-compose restart`) 才能生效。
