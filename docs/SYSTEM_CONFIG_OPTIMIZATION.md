# System Config 使用逻辑优化

## 优化目标

解决菜单、页面模板、AI工作流三者之间的数据关联问题，实现自动关联，避免手动重复输入。

## 优化内容

### 1. 数据库变更

**新增字段**：`sys_menu.page_key` (TEXT UNIQUE)
- 页面唯一标识符
- 从菜单的 `path` 自动提取（格式：`/dashboard/{page_key}`）
- 作为三个模块的关联键

**数据迁移**：
- 已自动从现有菜单的 `path` 字段中提取 `page_key`
- 示例：`/dashboard/loan_risk` → `loan_risk`

---

### 2. 菜单管理优化

#### ✅ 新增菜单
- **改前**：手动输入完整路径（如：`/dashboard/loan_risk`）
- **改后**：只需输入 `page_key`（如：`loan_risk`），系统自动生成路径
- **校验**：自动检查 `page_key` 是否已被使用，避免重复

#### ✅ 编辑菜单
- 支持修改 `page_key`
- 修改后自动更新对应的 `path`
- 自动校验新的 `page_key` 是否与其他菜单冲突

#### ✅ 字段要求
- `page_key` 仅允许：字母、数字、下划线、连字符
- 格式验证：`/^[a-zA-Z0-9_-]+$/`

---

### 3. 页面模板管理优化

#### ✅ 新增页面模板
1. **关联菜单**（新增）：
   - 下拉选择已有菜单
   - 自动填充：`page_key` 和 `title`
   
2. **手动输入**（保留）：
   - 也可以直接手动输入 `page_key` 和 `title`
   - 支持创建独立页面（不关联菜单）

#### 📋 数据流
```
选择菜单 → 自动填充 → 可手动调整 → 提交保存
```

---

### 4. AI 工作流配置优化

#### ✅ 新增工作流配置
1. **关联页面模板**（新增）：
   - 下拉选择已有页面模板
   - 自动填充：`page_key` 和 `workflow_name`（页面标题 + "工作流"）
   
2. **手动输入**（保留）：
   - 也可以直接手动输入
   - 灵活性更高

---

## 使用流程

### 推荐工作流程

```
1. 菜单管理
   ↓ 新增菜单，输入 page_key: "loan_risk"
   
2. 页面模板管理  
   ↓ 选择菜单"贷后风险分析"，自动填充 page_key 和 title
   ↓ 编辑 AMIS Schema
   
3. AI 工作流配置
   ↓ 选择页面"贷后风险分析"，自动填充配置
   ↓ 填写 API Key 等
```
