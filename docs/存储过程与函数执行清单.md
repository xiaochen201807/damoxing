## 5. 各数据库建议执行顺序

### 5.1 Oracle

执行顺序：

1. 执行 [init_business_standards_oracle.sql](/Users/xiaochen/Downloads/damoxing/server/data/init_business_standards_oracle.sql)
2. 执行 [update_calc_objects_oracle.sql](/Users/xiaochen/Downloads/damoxing/server/data/update_calc_objects_oracle.sql)
4. 导入标准库与规则数据

说明：

- 第 2 步已经包含 JSON 方言解析函数及更新后的主过程/函数。

### 5.2 达梦

执行顺序：

1. 执行 [init_business_standards_dm.sql](/Users/xiaochen/Downloads/damoxing/server/data/init_business_standards_dm.sql)
2. 执行 [update_calc_objects_dm.sql](/Users/xiaochen/Downloads/damoxing/server/data/update_calc_objects_dm.sql)
4. 导入标准库与规则数据

### 5.3 PostgreSQL

执行顺序：

1. 执行 [init_pg_family_demo_tables.sql](/Users/xiaochen/Downloads/damoxing/server/data/init_pg_family_demo_tables.sql)
2. 执行 [init_pg_family_db_format_pg.sql](/Users/xiaochen/Downloads/damoxing/server/data/init_pg_family_db_format_pg.sql)
3. 执行 [init_pg_family_calc_objects_common.sql](/Users/xiaochen/Downloads/damoxing/server/data/init_pg_family_calc_objects_common.sql)
4. 导入四张表数据，可使用 [import_pg_family_exports.js](/Users/xiaochen/Downloads/damoxing/server/scripts/import_pg_family_exports.js)

### 5.4 openGauss

执行顺序：

1. 执行 [init_pg_family_demo_tables_gauss.sql](/Users/xiaochen/Downloads/damoxing/server/data/init_pg_family_demo_tables_gauss.sql)
2. 执行 [init_pg_family_db_format_gauss.sql](/Users/xiaochen/Downloads/damoxing/server/data/init_pg_family_db_format_gauss.sql)
3. 执行 [init_pg_family_calc_objects_common.sql](/Users/xiaochen/Downloads/damoxing/server/data/init_pg_family_calc_objects_common.sql)
4. 执行 [init_pg_family_calc_objects_gauss_compat.sql](/Users/xiaochen/Downloads/damoxing/server/data/init_pg_family_calc_objects_gauss_compat.sql)
5. 导入四张表数据，可使用 [import_pg_family_exports.js](/Users/xiaochen/Downloads/damoxing/server/scripts/import_pg_family_exports.js)

说明：

- 第 4 步必须执行，否则 `f_gjj_get_sql_by_dialect`、`f_arg_list` 的兼容行为不完整。

### 5.5 Kingbase

执行顺序：

1. 执行 [init_pg_family_demo_tables.sql](/Users/xiaochen/Downloads/damoxing/server/data/init_pg_family_demo_tables.sql)
2. 执行 [init_pg_family_db_format_kingbase.sql](/Users/xiaochen/Downloads/damoxing/server/data/init_pg_family_db_format_kingbase.sql)
3. 执行 [init_pg_family_calc_objects_common.sql](/Users/xiaochen/Downloads/damoxing/server/data/init_pg_family_calc_objects_common.sql)
4. 导入四张表数据，可使用 [import_pg_family_exports.js](/Users/xiaochen/Downloads/damoxing/server/scripts/import_pg_family_exports.js)
