## 一、手册说明

## 四、配置文件修改说明

### 1. 配置文件位置

业务库配置文件为：

```text
server/config/datasources.json
```

生产部署时，通常挂载为：

```text
config/datasources.json
```

### 2. 全局字段说明

| 字段 | 说明 |
|----|----|
| `default_datasource` | 默认数据源 ID，必须等于某个 `datasources[].id` |
| `strict_routing` | 是否开启严格路由，生产建议 `true` |

### 3. 每个数据源必须配置的字段

| 字段 | 说明 |
|----|----|
| `id` | 数据源标识 |
| `type` | 数据库类型 |
| `jgbh_list` | 该数据源负责的机构编号列表 |
| `config.user` | 数据库用户名 |
| `config.password` | 数据库密码 |
| `config.connectString` 或 `config.host/port/database` | 连接信息 |
| `config.poolMin` / `config.poolMax` | 连接池参数 |

### 4. 数据源类型说明

当前程序规则控制初始化脚本支持以下类型：

| 类型值 | 数据库 |
|----|----|
| `oracle` | Oracle |
| `dm` | 达梦 |
| `pg` | PostgreSQL |
| `gauss` | openGauss |
| `kingbase` | 人大金仓 |

### 5. 配置示例

以下示例仅用于说明格式，交付时请替换为现场真实值，不要直接照抄。

#### 5.1 Oracle 示例

```json
{
  "id": "oracle_main",
  "type": "oracle",
  "jgbh_list": ["YOUR_JGBH"],
  "config": {
    "user": "YOUR_USER",
    "password": "YOUR_PASSWORD",
    "connectString": "YOUR_HOST:1521/YOUR_SERVICE",
    "poolMin": 2,
    "poolMax": 10
  }
}
```

#### 5.2 达梦示例

```json
{
  "id": "dm_main",
  "type": "dm",
  "jgbh_list": ["YOUR_JGBH"],
  "config": {
    "user": "YOUR_USER",
    "password": "YOUR_PASSWORD",
    "connectString": "YOUR_HOST:5236",
    "loginEncrypt": false,
    "poolMin": 2,
    "poolMax": 10
  }
}
```

#### 5.3 人大金仓示例

```json
{
  "id": "kingbase_main",
  "type": "kingbase",
  "jgbh_list": ["YOUR_JGBH"],
  "config": {
    "user": "YOUR_USER",
    "password": "YOUR_PASSWORD",
    "connectString": "YOUR_HOST:54321/YOUR_DATABASE",
    "poolMin": 2,
    "poolMax": 10
  }
}
```

### 6. 修改原则

| 步骤 | 说明 |
|----|----|
| 1 | 先确认现场数据库类型 |
| 2 | 再确认每个机构编号应该路由到哪个数据库 |
| 3 | 再填写账号、密码、连接串 |
| 4 | 再确认 `default_datasource` 和 `strict_routing` |
| 5 | 启动程序前确认 JSON 格式正确 |

## 五、表结构说明

程序规则控制只涉及一张核心业务表：`gjj_cxgzkz`。

### 1. 表字段说明

| 字段名 | 含义 | 说明 |
|----|----|----|
| `id` | 主键ID | 自增主键 |
| `jgbh` | 机构编号 | 机构隔离字段 |
| `zjgbh` | 子机构编号 | 子机构隔离字段 |
| `sxbh` | 事项编号 | 对应事项主数据编号 |
| `gzmc` | 程序控制规则名称 | 规则标题 |
| `gztsy` | 程序控制规则提示语 | 规则提示内容 |
| `sfqy` | 是否启用 | `y/n`，默认 `y` |
| `sfyxtqy` | 是否允许停启用 | `y/n`，默认 `y` |
| `sfyxtztsy` | 是否允许调整提示语 | `y/n`，默认 `n` |
| `role` | 角色 | 预留字段，可为空 |

### 2. 建议索引

| 索引 | 用途 |
|----|----|
| `(jgbh, zjgbh)` | 按机构、子机构查询时加速 |
| `(sxbh)` | 按事项编号查询时加速 |

## 八、表数据导入说明

| `是否允许停启用` | 否 | `y/n` 或 `是/否` |
| `是否允许调整提示语` | 否 | `y/n` 或 `是/否` |

## 十一、插入贝贝工作台步骤

### 1. 查询对象定义的执行角色

连接平台业务库后，先执行以下 SQL，查询“对象定义”对应记录并记录 `ZXJSID` 字段的值：

```sql
SELECT *
FROM PT_JG_SX_CSH
WHERE JGBH = '1305282025'
  AND SXMC LIKE '对象定义';
```

执行后记录查询结果中的 `ZXJSID`，例如：`10074548`。

注意事项：

- `JGBH` 需要替换为本中心自己的机构编号
- SQL 中不要保留机构编号末尾的空格

### 2. 插入“程序规则控制管理”菜单

查询到执行角色后，执行插入语句：

```sql
insert into PT_JG_SX_CSH (ID, JGBH, SXFL, SXBS, SXMC, BD_URL, TB_URL, ZXJSID, ZDLX, CPBS, BKMC)
values (
    f_newid(),
    '1305282025',
    '数据中台',
    '-10289',
    '程序规则控制管理',
    'https://appcs.jbysoft.com/gjj_gjsjjsmx/cxgzkz/cxgzkz',
    ' ',
    '10075208,10076373,1001068652271,10074548',
    '0',
    'bbPro',
    '数据应用'
);
```

执行前请按现场环境替换以下内容：

- `JGBH`：替换为本中心自己的机构编号
- `BD_URL`：将域名前缀替换为现场实际访问地址，路径保持 `/gjj_gjsjjsmx/cxgzkz/cxgzkz`
- `ZXJSID`：将末尾拼接为上一步查询得到的执行角色 ID

示例中 `ZXJSID` 为：

```text
10075208,10076373,1001068652271,10074548
```

其中最后一个 `10074548` 需要替换为现场查询得到的角色 ID。
