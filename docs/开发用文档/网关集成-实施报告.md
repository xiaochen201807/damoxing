## 访问方式

### URL 格式
```
https://your-domain/gjjrgzn/login?ticket=xxx&tyLoginToken=xxx&qycode=xxx
```

### 参数说明

| 参数 | 必填 | 说明 | 示例 |
|------|------|------|------|
| `ticket` | 是 | 网关验证票据 | `tyrz1b7cf1ae2abc4c5faa15680ae2abe0fb` |
| `tyLoginToken` | 是 | 网关登录令牌 | `bc8f5b4845114d984d802677cf2a15ba63:zmd` |
| `qycode` | 是 | 企业代码 | `250307` |

---

## 后续请求头列表

登录成功后，**所有 API 请求**会自动携带以下请求头：

### 1. JWT 认证
```
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### 2. 网关相关参数

#### `channel`
```
channel: zmd
```
- **提取规则**: 从 `tyLoginToken` 中截取冒号后面的部分
- **示例**: `bc8f5b48:zmd` → `zmd`

#### `login-token`
```
login-token: bc8f5b4845114d984d802677cf2a15ba63:zmd
```
- **来源**: 前端 URL 参数 `tyLoginToken`

#### `jgbh` (机构编号)
```
jgbh: 1305282025
```
- **来源**: 网关响应 `user_info.zzjgxx.results.jgmsg.jgbh`

#### `zzbs` (组织标识)
```
zzbs: 1305282025
```
- **来源**: 网关响应（与 `jgbh` 相同）

#### `zzjgdmz` (组织机构代码证)
```
zzjgdmz: 250307
```
- **来源**: 前端 URL 参数 `qycode`

## 完整数据流

### 1. 访问应用
```
http://localhost:3000/gjjrgzn/login?ticket=tyrz1b7cf&tyLoginToken=bc8f5b48:zmd&qycode=250307
```

### 2. 前端处理
- 解析 URL 参数
- 保存到 `sessionStorage`（防止刷新丢失）

### 3. 登录请求
```http
POST /gjjrgzn/api/auth/login

{
  "username": "admin",
  "password": "admin123",
  "ticket": "tyrz1b7cf",
  "tyLoginToken": "bc8f5b48:zmd",
  "qycode": "250307"
}
```

### 4. 后端处理
- 验证用户名密码
- 调用第三方网关 API
- 解析网关响应中的 `user_info`
- 提取 `jgbh`、`grbh`、`xingming` 等字段

### 5. 登录响应
```json
{
  "status": 0,
  "data": {
    "token": "eyJhbGc...",
    "user": {...},
    "gateway_info": {
      "jgbh": "1305282025",
      "zzbs": "1305282025",
      "zzjgdmz": "250307",
      "login_token": "bc8f5b48:zmd"
    }
  }
}
```

### 6. 前端存储
```javascript
localStorage.setItem('auth_token', token);
localStorage.setItem('gateway_info', JSON.stringify(gateway_info));
```

### 7. 后续请求自动携带
```http
GET /gjjrgzn/api/system/menu
Authorization: Bearer eyJhbGc...
channel: zmd
login-token: bc8f5b48:zmd
jgbh: 1305282025
zzbs: 1305282025
zzjgdmz: 250307
```

## 故障排查

### 问题 1: 请求头缺失
**排查**: 
```javascript
// 浏览器控制台
console.log(localStorage.getItem('gateway_info'));
```

### 问题 2: channel 为空
**原因**: `tyLoginToken` 中没有冒号

**检查**: 确保 URL 参数格式为 `tyLoginToken=xxx:zmd`

### 问题 3: 网关调用失败
**查看后端日志**:
```
[Gateway] 调用网关验证接口: https://...
[Gateway] 网关响应成功
[Gateway] 解析到: jgbh=..., zzbs=...
```
