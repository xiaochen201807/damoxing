# 快速部署指南

## 📋 部署前准备

### 验证配置文件（可选）
```bash
# 检查前端 API 配置
cat client/.env.production | grep VITE_API_BASE_URL
# 应该显示: VITE_API_BASE_URL=

# 检查 docker-compose 配置
cat docker-compose.yml | grep -A 5 environment
# 应该包含: CORS_ORIGIN=*
```

> **注意**：不需要手动创建 `data/` 目录或复制数据库！  
> 容器首次启动时会自动初始化。

---

## 🚀 一键部署

```bash
# 构建并启动（首次会自动初始化数据库）
docker-compose up -d --build

# 查看启动日志
docker-compose logs -f
```

**就这么简单！** 容器会自动：
- ✅ 创建 `data/logs` 和 `data/backups` 目录
- ✅ 从模板初始化数据库（如果不存在）
- ✅ 启动 Nginx、Node.js 和定时备份任务

### 可选：不使用缓存重新构建
```bash
docker-compose build --no-cache
docker-compose up -d
```

---

## ✅ 验证部署

### 1. 检查容器状态
```bash
docker ps
# 应该显示: STATUS = Up X minutes (healthy)
```

### 2. 检查进程
```bash
docker exec -it damoxing-app ps aux
# 应该看到:
# - supervisord
# - nginx
# - node
# - crond (定时任务)
```

### 3. 测试服务
```bash
# 健康检查
curl http://localhost/health

# API 测试
curl http://localhost/api/system/menu

# 浏览器访问
# http://localhost
```

### 4. 验证备份功能
```bash
# 手动触发备份测试
docker exec -it damoxing-app /app/backup-db.sh

# 查看备份文件
ls -lh data/backups/

# 查看备份日志
cat data/logs/backup.log
```

## 📁 目录结构

部署后的目录结构：
```
damoxing/
├── data/                              # 唯一需要挂载的目录
│   ├── database.sqlite                # 数据库文件
│   ├── logs/                          # 日志目录
│   │   ├── app.log                    # 应用日志
│   │   ├── error.log                  # 错误日志
│   │   └── backup.log                 # 备份日志
│   └── backups/                       # 自动备份目录
│       ├── database_20231217_020000.sqlite
│       └── database_20231218_020000.sqlite
├── client/
├── server/
├── docker-compose.yml
├── Dockerfile
├── backup-db.sh                       # 备份脚本
└── crontab                            # 定时任务配置
```

## 🔧 常用命令

### 容器管理
```bash
# 启动
docker-compose up -d

# 停止
docker-compose down

# 重启
docker-compose restart

# 查看日志
docker-compose logs -f

# 进入容器
docker exec -it damoxing-app sh
```

### 备份管理
```bash
# 手动备份
docker exec -it damoxing-app /app/backup-db.sh

# 查看备份
ls -lh data/backups/

# 查看备份日志
tail -f data/logs/backup.log
```

### 数据恢复
```bash
# 1. 停止容器
docker-compose down

# 2. 恢复备份
cp data/backups/database_YYYYMMDD_HHMMSS.sqlite data/database.sqlite

# 3. 重启容器
docker-compose up -d
```

---

## ⚠️ 注意事项

1. **首次部署必须创建 data 目录并复制数据库**
2. **备份每天凌晨 2 点自动执行，保留 7 天**
3. **只需挂载一个 data 目录，包含所有数据**
4. **CORS 已设置为 `*`，支持任意 IP 访问**

## 🆘 故障排查

### 容器状态为 unhealthy
```bash
# 查看详细日志
docker logs damoxing-app

# 检查健康检查
curl http://localhost/health
```

### 页面空白
```bash
# 检查前端文件
docker exec -it damoxing-app ls -la /usr/share/nginx/html/

# 检查 Nginx 日志
docker exec -it damoxing-app cat /var/log/nginx/error.log
```

### 备份未执行
```bash
# 检查 cron 进程
docker exec -it damoxing-app ps aux | grep crond

# 查看备份日志
cat data/logs/backup.log

# 手动测试备份
docker exec -it damoxing-app /app/backup-db.sh
```
