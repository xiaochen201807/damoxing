## 🔒 安全配置建议

### 1. HTTPS 配置
在外层 Nginx 配置 SSL/TLS：
```nginx
server {
    listen 443 ssl http2;
    server_name appcs.jbysoft.com;
    
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    
    location /gjjrgzn/ {
        proxy_pass http://localhost:80/gjjrgzn/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### 2. 防火墙规则
```bash
# 只开放必要端口
ufw allow 22/tcp   # SSH
ufw allow 80/tcp   # HTTP
ufw allow 443/tcp  # HTTPS
ufw enable
```

### 3. 容器安全
```yaml
# docker-compose.prod.yml 中添加
security_opt:
  - no-new-privileges:true
read_only: true
tmpfs:
  - /tmp
```

## 💾 数据备份策略

### 自动备份脚本
```bash
#!/bin/bash
# /usr/local/bin/backup-damoxing.sh

BACKUP_DIR="/backups/damoxing"
DATE=$(date +%Y%m%d_%H%M%S)

# 创建备份目录
mkdir -p $BACKUP_DIR

# 备份数据库
docker exec damoxing-app sqlite3 /app/data/database.sqlite ".backup '/app/data/backups/db_$DATE.sqlite'"

# 复制到外部备份目录
docker cp damoxing-app:/app/data/backups/db_$DATE.sqlite $BACKUP_DIR/

# 保留最近7天的备份
find $BACKUP_DIR -name "db_*.sqlite" -mtime +7 -delete

echo "Backup completed: $BACKUP_DIR/db_$DATE.sqlite"
```

### 定时任务
```bash
# crontab -e
# 每天凌晨2点备份
0 2 * * * /usr/local/bin/backup-damoxing.sh >> /var/log/damoxing-backup.log 2>&1
```
